# messageformat

> [!IMPORTANT]
> This is a port of the official [Unicode MessageFormat 2 (MF2) JS implementation](https://github.com/messageformat/messageformat) to Swift. While this is supposed to be _used_ in a way idiomatic to Swift, the internal API is kept as close to the original JS implementation as possible to make it easier to port future changes.
>
> The current base for implementation is commit 54caa72b6d6ece79e8e0d837dcbb7d703ad78877.
